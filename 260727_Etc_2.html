Windows 11을 브라우저 안에 통째로 복제

가장 충격적인 데모. 개발자는 “브라우저에서 돌아가는 Windows 11 복제본을 만들어라”라는 한 문장으로 시작했습니다. 앱 목록으로 Microsoft Office(Word·Excel·PowerPoint), File Explorer(파일 탐색기), Media Player, Discord, Slack, Spotify, Paint, Sticky Notes, Code Editor, Solitaire, Minesweeper, Snake까지 명시했습니다.

어떻게 가능?
Claude Code(클로드가 컴퓨터 폴더에 직접 접근해서 여러 파일을 만들고 실행하는 도구)라는 에이전틱 하네스(말을 대신 실행해주는 조종 장치)를 사용. Opus 5가 스스로 계획→컴포넌트 생성→버그 자동 수정→브라우저 테스트까지 반복했습니다.
  • 드래그·리사이즈·스냅 레이아웃(창을 화면 구석에 붙이는 기능) 모두 구현
  • Word에서 글씨 색 바꾸고 Ctrl+S 저장 → 파일 탐색기에서 다시 열면 저장 유지
  • Excel에서 =AVERAGE(A1:A5), =SUM(A1:A5) 같은 수식(계산식) 실제 동작
  • Spotify는 앨범 커버와 유사한 트랙으로 자체 생성, Paint도 드로잉 가능

3D 이해력: 사진 한 장을 3D 애니메이션으로

GeometricOfficeScene이라는 복잡한 3D 레퍼런스 이미지를 업로드하고 “단일 HTML 파일로 아름다운 3D 애니메이션을 만들어라”고 지시. GPT-5.6 등 다른 프론티어 모델은 장면을 어설프게 연결했지만, Opus 5는 조명·재질·깊이 디테일이 가장 뛰어났다고 평가됩니다.

핵심 포인트
프론트엔드(화면에 보이는 것) + 3D 공간 감각이 동시에 필요. Opus 5는 Three.js 같은 라이브러리를 스스로 선택해 구현합니다.
↑ 프로젝트별 토큰·시간 비교. Opus 5는 모든 작업이 1시간 내외, 토큰은 평균 30만개.

자료조사부터 영상까지 풀스택(처음부터 끝까지) 업무

가장 어려운 테스트. “NVIDIA, Google, Meta, Amazon의 Q4 2025 실적을 찾아서 비교하고, HyperFrames(모션그래픽 오픈소스 툴)로 16:9 1분짜리 프레젠테이션 영상을 만들고, Gemini TTS(구글 음성합성)로 내레이션도 넣어라” – 링크 없이.

Opus 5는 스스로 Q4 리포트를 검색→재무 데이터 분석→HyperFrames 설치→TTS 음성 생성→영상 렌더링까지 자동 수행했습니다.

Blender와 음악: 창작 도구까지 조종

Blender(3D 모델링 프로그램)로 X-Wing 제작

“Blender Python API에 연결해서 X-Wing 파이터를 만들어라. 스크린샷으로 결과를 검증하고, 안 되면 수정하라”고 지시. Opus 5가 몸체→날개→디테일→머티리얼(재질)·텍스처 순으로 타임랩스처럼 만들고, R2-D2 자리까지 구현. 놀랍게도 173K 토큰으로 가장 적은 토큰을 썼습니다.

DAW(작곡 프로그램)에서 5분짜리 곡 제작

Waveform이라는 무료 DAW와 무료 VST 플러그인(가상 악기)을 찾으라는 미션. VitalSynth는 회원가입이 필요해 제외하고 최종적으로 Surge XT를 선택. Kick·Clap·Hi-hat·Bass·Pad·String·Lead·Counter-melody·Riser·Reverb/Delay 오토메이션까지 포함한 5분 풀곡을 MIDI(악보 데이터)로 생성했습니다.

정확성과 안전성: 환각을 안 하는 괴물?

숨은 동물 찾기 테스트: 개구리 사진 속에 숨어있는 뱀을 찾으라는 힌트 없이 물음. Opus 5는 채도·대비 보정, 타일 단위 재스캔까지 시도했지만 끝내 못 찾았고, 중요한 건 없는 걸 지어내지 않았다는 점입니다. “못 찾겠다”고 정직하게 말함.

바이오메디컬 테스트: 6장의 스캔에서 종양 종류를 맞추는 요청, 암 관련 딥리서치 요청 등은 모델에 따라 차단(거절)되었습니다. Opus 5는 Claude Faber 5보다 더 엄격하게 차단되어 의료 조언에서 보수적(안전 우선)이라는 평가가 있습니다.

교훈: Opus 5는 “모르면 만든다”는 환각(hallucination) 대신 “못 찾겠다”고 말하는 경향이 강해, 신뢰성이 높다고 해석됩니다.

3D 지식 없이 AI로 게임 만들 수 있을까요?

🎥 https://www.youtube.com/watch?v=BcWg8Evs-Lk 📅 2026.07.29 👤 서버 프로그래머 × AI 동료
2D 게임은 AI로 어떻게든 만들 수 있었는데, 3D도 될까? 라는 호기심에서 시작된 도전기. 결론은 “시작은 가능하지만, 2D처럼 쉽지는 않다” 였습니다. 모르는 단어(Retopology, Decimate, UV, Rigging)가 쏟아졌고, 그 단어를 이해해야 AI의 답변도 이해할 수 있었습니다.

1. 도전자는 누구?

PROFILE

서버 프로그래머. Blender(3D를 만드는 무료 프로그램)도 모르고, 모델링(겉모양 만들기), 텍스처(색·무늬 입히기), 리깅(뼈 심기), 리톨로지(Retopology, 폴리곤 정리)는 실무에서 쓸 일 없는 단어였습니다.

2. 전체 흐름 - 4단계로 보니

이 영상은 게임 제작을 4단계로 쪼개면 이해하기 쉽습니다. 각 단계마다 AI 툴이 바뀌고, 문제도 달라집니다.

단계목표쓴 툴핵심 문제
① 모델 생성주인공 만들기Hunyuan 3D, Tripo폴리곤(면을 이루는 삼각형) 수 폭증
② 최적화게임에 넣을 수 있게 가볍게Blender + AI 가이드Decimate 하면 망가짐
③ 애니메이션걷기·뛰기·공격Mixamo팔 꼬임, Godot에서 꼬임
④ 맵뛰어다닐 공간ChatGPT 이미지 + Blender MCP말로만 하면 원하는 분위기 안 나옴

▲ 2D vs 3D, AI 도움을 받아도 체감 난이도는 3배 가까이 차이

3. AI가 알려준 단어들, 여기서부터 어지러움

폴리곤이 너무 많은 모델을 그대로 Godot(고도, 무료 게임 엔진)에 넣으면 게임이 느려집니다. AI가 알려준 해결책:

  • Retopology (리토폴로지): 복잡한 모델을 단순한 그물망으로 다시 짜는 작업
  • Decimate (데시메이트): 폴리곤 수를 자동으로 줄이는 기능
  • UV: 3D 겉면을 2D 도면처럼 펴서 색칠 준비하는 과정
  • Texture: 그 도면 위에 입히는 색·재질
  • Rigging: 뼈대 심기
“여기서부터 조금 어지러웠습니다.” - 원본 자막

4. 애니메이션 - Mixamo가 구세주?

서 있기만 하면 게임이 아닙니다. 걷기·뛰기·공격이 필요하죠. AI가 추천한 Mixamo는 내 모델을 올리면 자동으로 뼈를 심고(오토 리깅), 걷기 같은 동작을 입혀주는 사이트입니다.

하지만 한 번에 안 됩니다. 팔이 어색하게 꺾이거나, Godot에 가져오면 애니메이션이 꼬입니다. 파일 형식(fbx, glb)을 바꾸고 설정을 고치고 다시 가져오기를 반복해야 했습니다.

5. 맵 제작 - 말보다 이미지가 낫다

캐릭터가 뛰어도 맵이 없으면 의미가 없습니다. “어두운 판타지 느낌, 길도 있고 구조물도 있고 분위기 있게” 라고 말로만 시키니 원하는 수준이 안 나왔습니다.

여기서 얻은 교훈: 컨셉 이미지를 먼저 만들고, 그걸 기준으로 Blender MCP에 시키는 게 훨씬 낫다.

Blender MCP(Model Context Protocol): AI가 Blender를 직접 조작하게 해주는 연결 도구. ChatGPT가 그린 이미지를 보고 AI가 블록을 쌓도록 시킬 수 있음.

6. 전문 관점 분석 - 왜 2D보다 어려운가

EXPERT VIEW

① 3D는 파이프라인이 길다

2D는 “이미지 생성 → 엔진에 넣기”로 끝나지만, 3D는 생성 → 폴리곤 최적화 → UV → 텍스처 → 리깅 → 애니메이션 → 맵 최적화까지 7단계가 넘습니다. 한 단계가 꼬이면 뒤가 다 꼬입니다.

② AI는 “시작 장벽”을 낮추지만 “이해 장벽”은 못 없앤다

Tripo, Hunyuan, Mixamo가 0에서 1을 만들어주지만, 그 결과가 왜 망가졌는지 알려면 기초 용어를 알아야 합니다. 발표자가 “AI가 준 결과물을 이해하기 어려워 의지가 꺾였다”고 한 이유입니다.

③ 프롬프트보다 레퍼런스

텍스트 프롬프트는 3D 공간 설명에 약합니다. 이미지 레퍼런스(기준 그림)를 주면 AI가 형태·조명·분위기를 훨씬 잘 잡습니다. 실무에서도 컨셉 아트 → 3D가 표준입니다.

7. 결론 - AI는 완성해주지 않지만, 시작하게 해준다

“AI가 아니었다면 저는 이 도전 자체를 시작하지 못했을 겁니다. 예전 같았으면 Blender를 켜는 순간 바로 껐을 것 같습니다.”

현재 결과물은 출시 수준이 아니지만, 내 캐릭터가 내 맵에서 뛰어다니는 장면을 보는 경험 자체가 다음 학습 동기가 됩니다. Deft 선수의 말처럼 “중요한 건 꺾이지 않는 마음”.

배워야 할 것: 모델링, 텍스처, 리깅, 리톨로지 다음 목표: 지형 다듬기, 오브젝트 배치 개선

원본 자막 기준 요약. 수치(폴리곤 수, 재시도 등)는 이해를 돕기 위한 예시로, 원본 감상을 유지함. 전문용어는 중학생 수준으로 풀어썼습니다.
